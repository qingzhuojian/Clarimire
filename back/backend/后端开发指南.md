# Clarimire 后端开发指南

## 环境要求

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 1.8+ | 必须使用 JDK 8 或更高版本 |
| Maven | 3.6+ | 项目依赖管理工具 |
| MySQL | 8.0+ | 数据库 |
| IDE | IntelliJ IDEA / VS Code | 推荐 IntelliJ IDEA |

---

## 一、环境配置

### 1.1 安装 JDK 8

**Windows:**
1. 下载 [JDK 8](https://www.oracle.com/java/technologies/javase/javase8-archive-downloads.html)
2. 安装并配置环境变量：
   - `JAVA_HOME` = `C:\Program Files\Java\jdk1.8.0_xxx`
   - 将 `%JAVA_HOME%\bin` 添加到 `Path`

**验证安装：**
```powershell
java -version
```

### 1.2 安装 Maven

**Windows:**
1. 下载 [Maven 3.8+](https://maven.apache.org/download.cgi)
2. 解压到 `D:\apache-maven` 或其他目录
3. 配置环境变量：
   - `MAVEN_HOME` = `D:\apache-maven`
   - 将 `%MAVEN_HOME%\bin` 添加到 `Path`

**验证安装：**
```powershell
mvn -version
```

### 1.3 安装 MySQL 8.0

1. 下载并安装 [MySQL 8.0](https://dev.mysql.com/downloads/mysql/)
2. 安装过程中设置 root 密码，**记住这个密码**
3. 验证安装：
```powershell
mysql -u root -p
```

## 二、项目初始化

### 2.1 创建数据库

1. 登录 MySQL：
```powershell
mysql -u root -p
```

2. 创建数据库（如果不存在）：
```sql
CREATE DATABASE IF NOT EXISTS water_data CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

### 2.2 导入数据库表结构

**方式一：使用完整建表脚本**
```powershell
mysql -u root -p water_data < back/backend/src/main/resources/db/clarimire.sql
```

**方式二：使用 MySQL Workbench 导入**
1. 打开 MySQL Workbench
2. 连接本地 MySQL
3. 选择 `water_data` 数据库
4. File -> Run SQL Script -> 选择 `clarimire.sql`

### 2.3 配置本地敏感信息

1. 进入后端目录：
```powershell
cd back/backend
```

2. 复制配置文件模板：
```powershell
copy src\main\resources\application-local.yml.example src\main\resources\application-local.yml
```

3. 编辑 `application-local.yml`，填入数据库用户名和密码：
```yaml
spring:
  datasource:
    username: root
    password: your_password_here

jwt:
  secret: ClarimireAquaGuardian-2026-SecureJWTSecretKey-xK9mP2vL8nQ5wZ7jR3tY6uI0oA
```

## 三、启动后端

### 3.1 使用 Maven 命令行启动

```powershell
cd back/backend
mvn spring-boot:run
```

### 3.2 使用 IDE 启动

**IntelliJ IDEA:**
1. File -> Open -> 选择 `back/backend` 目录
2. 等待 Maven 索引完成（右下角进度条）
3. 打开 `ClarimireApplication.java`
4. 右键 -> Run 'ClarimireApplication'
5. 或者点击右上角绿色运行按钮

**VS Code:**
1. 安装扩展：`vscjava.vscode-java-pack`
2. 打开 `back/backend` 目录
3. 按 `F5` 启动调试

### 3.3 启动脚本（Windows）

双击运行 `back/backend/启动后端.bat`

## 七、常见问题

### 7.1 端口被占用

```
Error: Address already in use: bind
```

**解决方法：**
```powershell
# 查找占用 8080 端口的进程
netstat -ano | findstr :8080

# 结束进程（假设 PID 是 1234）
taskkill /PID 1234 /F
```

### 7.2 数据库连接失败

```
Connection refused: connect
```

**检查清单：**
- [ ] MySQL 服务是否启动（`services.msc`）
- [ ] 数据库用户名密码是否正确
- [ ] `application-local.yml` 是否正确配置

**启动 MySQL 服务：**
```powershell
net start mysql80
```

### 7.3 Maven 下载依赖失败

**解决方法：**
```powershell
# 清理并重新下载
mvn clean install -U
```

### 7.4 Swagger 页面打不开

访问 http://localhost:8080/doc.html

如果打不开，检查：
- 后端是否正常启动
- 控制台是否有错误日志
- 确保访问的是 `/doc.html` 而不是 `/swagger-ui.html`

## 八、热部署（可选）

如果想在修改代码后自动重载，可以添加 spring-boot-devtools：

### 8.1 添加依赖

在 `pom.xml` 中添加：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```
### 8.2 IDE 配置

**IntelliJ IDEA:**
1. Settings -> Build -> Compiler -> 勾选 "Build project automatically"
2. Settings -> Advanced Settings -> 勾选 "Allow auto-make to start"
