# 后端连接错误诊断

## 错误信息分析

从终端错误信息看到：
```
[vite] http proxy error at /api/waterSituation/list?page=1&pageSize=10&reservoirName=:
AggregateError [ECONNREFUSED]
```

**错误含义：** `ECONNREFUSED` 表示连接被拒绝，说明后端服务（端口8080）没有运行。

## 问题原因

1. ✅ **CORS配置已修复** - 已添加3002端口到允许列表
2. ❌ **后端服务未启动** - 这是当前的主要问题
3. ✅ **重复CORS配置已修复** - 已移除 `ClarimireApplication.java` 中的重复配置

## 解决步骤

### 第一步：启动后端服务

#### 方式1：使用已编译的jar文件（推荐）
```bash
cd back/backend
java -jar target/clarimire-backend-1.0.0.jar
```

如果没有jar文件，需要先编译：
```bash
cd back/backend
mvn clean package
java -jar target/clarimire-backend-1.0.0.jar
```

#### 方式2：使用Maven直接运行
```bash
cd back/backend
mvn spring-boot:run
```

#### 方式3：使用提供的启动脚本
双击运行 `启动后端.bat` 文件

### 第二步：确认后端启动成功

启动成功后，应该看到类似以下的输出：
```
Started ClarimireApplication in X.XXX seconds
Tomcat started on port(s): 8080 (http)
```

### 第三步：测试后端连接

在浏览器中访问：`http://localhost:8080/api/test/hello`
应该返回：`Hello from backend!`

### 第四步：检查前端连接

前端应该能够正常连接后端，不再出现 `ECONNREFUSED` 错误。

## 可能遇到的问题

### 1. 数据库连接错误

如果启动时出现数据库连接错误，需要：
- 检查MySQL服务是否运行
- 检查 `application.yml` 中的数据库配置
- 确保数据库已创建（建议使用 `water_data` 数据库）
- 执行SQL文件初始化表结构

### 2. 端口被占用

如果8080端口被占用：
- 修改 `application.yml` 中的端口号
- 或关闭占用8080端口的程序

### 3. Maven未安装

如果提示找不到Maven：
- 安装Maven并配置到PATH
- 或使用IDE（如IntelliJ IDEA、Eclipse）来运行项目
